# MIDI 頭出しツール (midi_head_align) / MIDI Head Align / MIDI 节拍对齐工具

AI採譜などで「テンポ表記が実際と違う（例: 表記120BPMだが本当は148BPM）」MIDIを、
**音の位置（実時間）は変えずに**正しいBPMのMIDIへ直すためのRustアプリです。

- MIDIをドラッグ&ドロップ（または「開く」）
- **ドラムトラックから本当のBPMを自動解析**（手入力もOK）
- ピアノロールのプレビューで**拍頭（頭出し）を自動＋手動で調整**
- 「書き出し」で正しいBPMのMIDIを保存
- **UIは 日本語 / English / 中文**（言語ファイルを追加・選択可能）

GUIは [egui/eframe](https://github.com/emilk/egui)、MIDIの読み書きは [midly](https://github.com/kornelski/midly) を使用。

---

## 起動方法

```sh
# 1) ビルド（初回のみ・数分かかります）
cd midi_head_align
cargo build --release

# 2) 起動
./target/release/midi_head_align
```

Finderから使う場合は次のどちらか:

- `run.command` をダブルクリック（未ビルドなら自動でビルド）
- `MIDI頭出しツール.app` をダブルクリック（`./make_app.sh` で再作成できます）

## 画面の使い方

左パネルは「枠で区切った4つのセクション」に整理されています。
ファイル未読み込みの間、2〜3のセクションはグレーアウトします。

```
┌──────────────────────────────────────────────────────────────┐
│ 開く / 再解析 / ファイル情報                  [言語 ▼] […]    │
├──────────────────┬───────────────────────────────────────────┤
│ ╭ 1. テンポ(BPM) ╮│                                           │
│ │ BPM [148.002]×2÷2│        ピアノロール（書き出し後の姿）     │
│ │ 手入力 [      ]  │        ＋ 拍/小節グリッド                │
│ │ 一致度 / 候補一覧 │                                           │
│ ╰────────────────╯│                                           │
│ ╭ 2. 頭出し ╮      │                                           │
│ │ オフセット           │                                     │
│ │ [=====|=====]  +18.1ms│                                   │
│ │ [-10][-1][+1][+10][0] │                                   │
│ │ [ドラムから自動]      │                                    │
│ │ [このBPMで再計算]     │                                    │
│ │ [最初のドラム打点を…] │                                    │
│ │ [先頭の音を小節頭に…] │                                    │
│ │ 小節頭の拍: (1)(2)(3)(4)│                                  │
│ ╰────────────────╯│                                           │
│ ╭ 3. 書き出し ╮    │                                           │
│ │ [ ] tick位置を保つ ││                                       │
│ │ 出力 [          ]  ││                                       │
│ │ [別名で保存][💾書き出し]│                                  │
│ ╰────────────────╯│                                           │
│ ╭ 4. 表示 ╮        │                                           │
│ │ 横倍率 [====]     ││                                        │
│ │ ☑16分線 ☑ドラム    ││                                       │
│ │ トラック一覧(スクロール)│                                  │
│ ╰────────────────╯│                                           │
└──────────────────┴───────────────────────────────────────────┘
```

### 1. テンポ (BPM)
ファイルを読み込むと即座にドラムからBPMを解析します。

- 数値はドラッグでも直接入力でも変更可（手入力OK）
- `×2` / `÷2` … オクターブ誤認（148 vs 74 vs 296 など）の補正
- 「候補」… 解析スコアの上位候補。クリックで採用
- 「一致度」は 1.0 に近いほど、発音が16分グリッドにきれいに乗っている＝信頼できる

### 2. 頭出し（拍グリッドの位置）
**音符は動かさず、グリッド側を合わせます。**

- `オフセット(ms)` … 拍グリッドの位置。ドラム解析で自動設定される
- `-10 / -1 / +1 / +10 / 0` … 微調整ボタン
- `ドラムから自動` / `このBPMで再計算` / `最初のドラム打点を拍頭に` / `先頭の音を小節頭に合わせる`
- `小節頭の拍: 1 2 3 4` … どの拍を小節の1拍目にするか（4拍子の位相）

ピアノロールで音符の頭が縦線（拍）に乗るように `オフセット` を追い込んでください。
**緑の縦線が書き出し後の小節1の頭**です。

### 3. 書き出し
- 既定では **「音の実時間はそのまま / グリッドだけ正しいBPM」** で書き出します
- `tick位置を保つ` をONにすると、tickはそのままでテンポ表記だけ変更（＝再生速度が変わる）

### 4. 表示
横倍率（px/拍）、16分の薄い線、トラックごとの表示ON/OFF。

## 言語 / Language / 语言

上部バーの右にある言語メニュー（既定: 日本語）から切り替えます。選択は `~/.midi_head_align.json` に保存され、次回起動時にも適用されます。

| ファイル | 言語 |
|---|---|
| `lang/ja.json` | 日本語 |
| `lang/en.json` | English |
| `lang/zh.json` | 中文（简体） |

- 3ファイルは**バイナリに埋め込まれている**ので、単体でも動作します。
- `lang/` に `*.json` を追加すると、言語メニューに自動で並びます。
- メニュー右の `…` ボタンから**任意の言語ファイル**を読み込むこともできます。
- 未翻訳のキーは日本語→キー名の順でフォールバックするので、**部分翻訳でもOK**です。

### 言語ファイルの書き方

```json
{
  "_code": "en",
  "_label": "English",
  "app.title": "MIDI Head Align",
  "status.detected": "Detected from {0}: {1} BPM / beat offset {2} ms / fit {3} ({4} onsets)"
}
```

`{0} {1} …` が実行時に置換されるプレースホルダです。キー一覧は `lang/ja.json` を参照してください。

## コマンドライン（GUIなしでも使えます）

```sh
# BPMと拍位置を解析して表示（言語指定も可）
./target/release/midi_head_align --detect input.mid --lang en

# 指定BPMで書き出し（実時間維持）
./target/release/midi_head_align --export input.mid output.mid --bpm 148.002 --offset-ms 18.12

# tick維持（テンポ表記だけ変更）
./target/release/midi_head_align --export input.mid output.mid --bpm 148 --keep-ticks

# 小節の位相をずらす（2拍目を小節頭にする）
./target/release/midi_head_align --export in.mid out.mid --bpm 148 --offset-ms 18 --bar-phase 1

# 言語: ja / en / zh / 任意の .json パス
./target/release/midi_head_align --detect in.mid --lang zh
./target/release/midi_head_align --detect in.mid --lang /path/to/mylang.json

# GUIでファイルを開いて起動
./target/release/midi_head_align input.mid
```

## 解析アルゴリズムの要点

1. **オンセット抽出**: チャンネル10（ドラム）の発音を抽出。キック/スネア=重み1.0、ハイハット=0.6 など。
   ドラムが無いファイルは全トラックの発音を使う。
2. **テンポ推定**: 45〜220BPMを0.1刻みで走査し、BPMごとに
   「16分音符の櫛型テンプレート（拍>8分>16分の重み）」への乗り具合を評価。
   90〜180BPMを好む弱い事前分布を掛けて ×2/÷2 の誤認を抑制。上位候補を0.002刻みで精密化。
3. **拍位置（頭出し）**: 位相ヒストグラムで初期値を求め、平均シフト法で
   16分グリッドに合わせ込み（実測で ±数ms まで収束）。
4. **書き出し**: 元ファイルのテンポマップで各イベントの実時間を計算し、
   新テンポ（単一テンポ）でのtickに再配置。`shift_sec` 分だけ前へずらして拍頭を小節線へ合わせる。

### 実例: `your_file.mid`（任意の MIDI）

| 項目 | 値 |
|---|---|
| 表記 | 120.000 BPM |
| 検出 | **148.002 BPM**（ドラムから） |
| 拍頭オフセット | +18.1 ms |
| 一致度 | 0.47 |

書き出し結果はノートの実時間が元と **最大0.21ms（0.5tick）** の誤差で一致し、
16分グリッドへの乗りは **RMS 7.2ms**（元データの量子化由来のジッタ）になります。

## 制約・注意

- SMPTE タイムコード形式（`Timing::Timecode`）のMIDIは未対応です。
- テンポチェンジを含むMIDIは「先頭テンポを基準に実時間を計算し、単一テンポで書き出す」動作になります（UIに警告表示）。
- 書き出し時に元のテンポメタイベントは削除され、単一テンポに置き換わります。
- ファイル読み込みのたびに元データを `Box::leak` しています（1ファイル数十KB程度、実用上問題ありません）。
- **小節頭（1拍目がどれか）** はドラムだけでは決められないことがあります。
  ピアノロールを見て「小節頭の拍」を選び直してください。
- 日本語/中国語の表示にはシステムフォント（macOS: `/Library/Fonts/Arial Unicode.ttf` など）を利用します。
